# Zethic Site — Documentation

Status: documentation-only area. The website source and production deployment are outside this change.

## Purpose

This directory records public-safe analysis and governance prerequisites for future site changes. It does not make an offer active, approve a price, certify a capability, or authorize a deploy.

## Documents

- `COMMERCIAL_GAP_ANALYSIS.md` — gap between the current homepage and the commercial pathways under evaluation.
- `PRESENCE_CHANNEL_GAP_ANALYSIS.md` — role of the website inside the broader presence and conversion ecosystem.
- `DRIVE_SOURCE_INDEX_2026-09-20.md` — sanitized source register. Full operational artifacts remain in restricted Google Drive.

## Governance

- `index.html`, `CNAME`, `robots.txt` and `sitemap.xml` remain unchanged.
- Offers, naming, scope, CTA, proof and pricing require human approval.
- Customer data, leads, private conversations, transcripts, financial data and restricted Drive content must not be committed to this public repository.
- Site implementation requires a separate reviewed change.
- Merge and deploy remain human actions.
